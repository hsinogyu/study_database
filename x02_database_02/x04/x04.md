# 서브쿼리

## 서브쿼리 소개

### 문제
- 우리 쇼핑몰에서 판매하는 상품들의 평균 가격보다 비싼 상품은 무엇이 있을까?

### 논리적인 해결 순서
- 쿼리 1: 판매하는 상품들의 평균 가격을 구한다
- 쿼리 2: 구한 평균을 가지고 비싼 상품을 구한다
- 문제
    - 번거로움
    - 오류에 취약함: 중간에 상품 가격이 바뀐다면 잘못된 기준으로 데이터를 조회 할 수 있음

### 서브 쿼리의 개념
- 하나의 SQL 쿼리 문 안에 또 다른 select 쿼리를 의미함
- 괄호 안에 있는 서브 쿼리가 먼저 실행됨
- 서브 쿼리의 결과를 바깥쪽 메인 쿼리에게 전달하여, 메인 쿼리가 그 결과를 사용해서 최종 작업을 수행함

### 서브 쿼리로 해결
```sql
select name, price
from products
where price > (select avg(price) from products);
```
- 순서
    - 데이터베이스는 괄호 안의 서브쿼리를 먼저 실행
    - 반환 결과는 단일 값을 가짐
    - 최종적으로 이 변환된 메인 쿼리가 실행되어 결과를 보여줌

### 서브 쿼리 종류와 특징
- where 절 외에도 쿼리의 다양한 위치에서 각기 다른 역할을 수행함
- 서브 쿼리는 반환하는 행과 컬럼의 수에 따라 종류가 나위며, 사용되는 위치와 연산자에 따라 그 역할이 결정됨

## 스칼라 서브쿼리

### 단일 컬럼 / 단일 행
- 결과가 오직 하나의 행, 하나의 컬럼으로 나오는 경우를 말함(스칼라 = `단 하나의 값`)

### 사용할 수 있는 연산자
- =, > , <, >=, <=, <>

### 문제
- 특정 주문(order_id = 1)을 한 고객과 같은 도시에 사는 모든 고객을 찾고 싶다

### 해결
```sql
select u.address
from orders o
inner join users u on o.user_id = u.user_id
where o.order_id = 1;

select *
from users u
where u.address = '주소';
```

```sql
select *
from users
where address = (select u.address
        from orders o
        inner join users u on o.user_id = u.user_id
        where o.order_id = 1
    );
```

### 스칼라 서브쿼리의 치명적 오류
- 반드시, 무슨 일이 있어도 단 하나의 행만 반환해야함

## 단일 컬럼, 다중 행 서브쿼리

### 문제
- 전자기기 카테고리에 속한 모든 상품들을 주문한 주문 내역을 전부 보고 싶다
- 순서
    - 전자기기 카테고리에 속한 상품들의 id를 모두 찾는다
    - 그 다음, orders 테이블에서 product_id가 우리가 찾아낸 id 목록 안에 포함된 주문들을 모두 찾는다

### IN 연산자: 목록에 포함된 값과 일치하는지 확인
- 특정 컬럼의 값이 괄호 안의 목록 중 하나라도 일치하면 참을 반환함
```sql
select *
from orders o
where o.product_id in (
    select p.product_id 
    from products p 
    where p.category = '전자기기'
    );
```

### ANY, ALL 연산자: 목록의 일부/모든 값과 비교
- `> ANY (서브쿼리)`: 서브쿼리가 반환한 여러 결과값 중 어느 하나보다만 크면 참
- `> ALL (서브쿼리)`: 서브쿼리가 반환한 여러 결과값 모두보다 커야만 참
- `< ANY (서브쿼리)`: 최대값보다 작으면 참
- `< ALL (서브쿼리)`: 최소값보다 작으면 참
- `= ANY (서브쿼리)`: IN 과 완전히 동일한 의미

### 실제 쇼핑몰 데이터로 ANY, ALL 사용해보기
- 문제 1: 전자기기 카테고리의 최솟값보다 비싼
```sql
select *
from products p1
where p1.price > ANY(
    select p2.price
    from products p2
    where p2.category = '전자기기'
);
```

- 문제 2: 전자기기 카테고리의 모든 상품보다 비싼 상품 찾기
```sql
select *
from products p1
where p1.price > ALL(
    select p2.price
    from products p2
    where p2.category = '전자기기'
);
```

## 다중 컬럼 서브쿼리

### 개념
- 서브쿼리의 select 절에 두 개 이상의 컬럼이 포함된 경우를 말함
- 메인쿼리의 where 절에서 여러 컬럼을 동시에 비교해야 할 때 매우 유용함

### 문제
- 우리 쇼핑몰의 고객 네이트(user_id = 2)가 한 주문(order_id = 3)이 있음
- 이 주문과 동일한 고객이면서 주문 처리 상태가(status)도 같은 모든 주문을 찾아보자 

### 다중 컬럼 서브쿼리로 문제 해결하기
```sql
select user_id, status from orders where order_id = 3;

select *
from orders
where (user_id, status) = (select user_id, status from orders where order_id = 3);
```

### 주의할 점
- 다중 컬럼 서브쿼리를 = 연산자와 함께 사용할 때
- 단일 행 서브쿼리와 마찬가지로 서브쿼리의 결과가 반드시 **하나의 행**

### 다중 컬럼 서브쿼리와 IN 연산자
- 각 고객별로 가장 먼저 한 주문의 주문 ID, 사용자 ID, 사용자 이름, 제품 이름, 주문 날짜를 조회
```sql
select
    o.order_id,
    u.user_id,
    u.name,
    p.name,
    o.order_date
from orders o
inner join users u on o.user_id = u.user_id
inner join products p on o.product_id = p.product_id
where (u.user_id, o.order_date) in ( -- 각 고객별 최초 주문
    select user_id, min(order_date)
    from orders
    group by user_id
);
```
